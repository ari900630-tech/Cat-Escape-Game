# Cat Escape Game

משחק תלת־ממד למובייל: העכבר נשלט באמצעות גרירת אצבע, החתול רודף אחריו, והעכבר אוסף גבינות צהובות.

## הפעלה
פתחו את GitHub Pages של המאגר. המשחק בנוי כאתר סטטי ולכן אין צורך בשרת או בבנייה מקומית.

## שליטה
- מגע/עכבר: גרירה מזיזה את העכבר.
- מקלדת: WASD או חיצי הכיוון.
- אספו כמה שיותר גבינות והימנעו מהחתול.

המשחק משתמש ב-Three.js דרך CDN ומותאם למסך טלפון.
